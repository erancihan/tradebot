# Program Design: portfolio companion

Written per epic, right before that epic's slices start. Approved by owner
delegation when written.

## E1: housekeeping

### Files
- `tests/test_code_shape.py` (new). Walks `tradebot/` and `tests/` with
  `ast`. Fails when a function or method body spans more than 60 lines.
  Fails when a module under `tradebot/` spans more than 200 lines. Prints
  the offenders with path and line. Tests modules have no module limit.
- `tradebot/cli/__init__.py` (new). `build_parser()` and `main()`. Each
  command group registers its own subparser through a `register(sub)`
  function, so the parser builder stays short.
- `tradebot/cli/common.py`: logging setup, summary printers, shared helpers.
- `tradebot/cli/demo.py`, `backtest.py`, `run.py`, `status.py`,
  `universe.py`, `data.py`: one module per top-level command.
- `tradebot/cli/arena.py`: `list`, `run`, `validate`, `history`, `show`.
- `tradebot/cli/arena_gate.py`: `gate` and its report helpers.
- `tradebot/cli/arena_journal.py`: `journal`.
- `tradebot/cli/arena_league.py`: `league`.
- `tradebot/cli/season.py`: `season {create,seed,list,standings,run}`.
- `pyproject.toml`: script entry stays `tradebot = "tradebot.cli:main"`.
- Modules flagged by the shape test are split along their existing section
  comments, one concern per file, package re-exports kept so imports in
  tests and `algos/` do not change:
  - `tradebot/arena/season.py` to `season/` package: `model.py` (config,
    store access), `feeds.py` (replay, Alpaca, stream feeds), `daemon.py`
    (market-hours loop).
  - `tradebot/arena/gate.py` to `gate/` package: `criteria.py`,
    `report.py`, `evaluate.py`.
  - `tradebot/arena/store.py`: `store.py` (runs) and `journal.py`.
  - `tradebot/consortium.py`: `consortium/` package: `voice.py`,
    `blend.py`, `panel.py`.
  - `tradebot/backtest.py`: `backtest/` package: `result.py`, `marks.py`,
    `runner.py`.
  - `tradebot/arena/runner.py`: `runner.py` and `isolation.py`.
  - `tradebot/selection.py`: `selection/` package: `base.py`, `ranked.py`,
    `regime.py`.
  - `tradebot/engine.py`: `engine.py` and `engine_pass.py` (the per-pass
    gather and submit steps), later folded into `advisor.py` in E3.
  - Web: `repository.py` into `repository/` (trading, arena, season),
    `jobs_service.py` into `jobs/` (registry, backtest, dryrun, frames),
    `schemas.py` and `routes/api.py` by page.
  - Data: `cache.py` into `cache.py` and `coverage.py`. `synthetic.py` into
    `synthetic.py` and `factor_panel.py`. `storage.py` into `storage/`
    (connection and schema, orders, bars, weights).
  - `universe.py` into `universe/` (screen, alpaca).
  - `broker/dryrun.py` into `dryrun.py` and `brackets.py`.
- Long functions are split into named steps: `cli build_parser` (per
  group), `gate.evaluate_gate` (one function per criterion plus an
  aggregator), `simulation.simulate` and `Backtester.run` (shared step
  helpers, lockstep test stays green), `engine.rebalance` (gather, gate,
  size, submit), `synthetic_factor_panel`, `consortium_service.panel`,
  `walk_forward`.
- Docs: `CLAUDE.md` rewritten to a map plus invariants plus gotchas, under
  300 lines. The research record and the audit history move to
  `docs/research-record.md` as a paper trail. `docs/PLAN.md` and
  `docs/DESIGN-HANDOFF.md` are deleted. `README.md` describes the companion
  flows first and the research tooling second.
- Mobile shell: `templates/base.html` gets a bottom tab bar component
  (`components/tabbar.html`) shown under `md`, the top nav stays above `md`.
  `tradebot/web/static/manifest.webmanifest` is served from a route in
  `routes/pages.py`. Icons are two PNG files generated by a script in
  `frontend/`, committed under `tradebot/web/static-src/` (not gitignored).

### Types and signatures
```python
# tests/test_code_shape.py
MAX_FUNCTION_LINES = 60
MAX_MODULE_LINES = 200
def iter_python_files(root: Path) -> Iterator[Path]: ...
def long_functions(path: Path, limit: int) -> list[str]: ...
def test_no_function_exceeds_limit() -> None: ...
def test_no_package_module_exceeds_limit() -> None: ...

# tradebot/cli/__init__.py
def build_parser() -> argparse.ArgumentParser: ...
def main(argv: list[str] | None = None) -> int: ...
# every tradebot/cli/<group>.py
def register(sub: argparse._SubParsersAction) -> None: ...
```

### Call stack
`tradebot.cli.main` -> `build_parser` -> `<group>.register(sub)` sets
`func=cmd_*` -> `args.func(args)` -> existing command bodies, unchanged.

### Test plan
- `test_no_function_exceeds_limit`: fails if any function body is over 60 lines.
- `test_no_package_module_exceeds_limit`: fails if any `tradebot/` module is over 200 lines.
- Existing CLI tests keep passing with `tradebot.cli.main` unchanged.
- `test_web.py` gains `test_manifest_is_served` and `test_tabbar_renders_on_every_page`.

### Least confident decisions
1. Module limit 200 for the package only. Tests are exempt from the module
   limit because splitting test files adds no value.
2. Splitting `backtest.py` and `simulation.simulate` risks the lockstep
   invariant. The shared step helpers must be used by both loops.
3. PWA without a service worker: pinning and full-screen work, offline does
   not. Offline is not a goal for a live trading view.
